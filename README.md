🎮 Jogo em Rede — Corrida até o Portal

📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um jogo em rede para dois jogadores, baseado na atividade proposta pelo professor. O objetivo é competir em uma corrida até o portal, utilizando os comandos de movimentação e salto para avançar pela fase.

🛠️ Ferramentas utilizadas

Godot Engine: criação e desenvolvimento do jogo.

GDScript: linguagem utilizada na programação das mecânicas.

▶️ Como executar

Instale a Godot Engine.

Abra o projeto na Godot.

Execute a cena principal para iniciar o jogo.

Projeto acadêmico desenvolvido em dupla para a disciplina de Fundamentos de Desenvolvimento de Jogos.
